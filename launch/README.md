# Shepherd launch media

Product video for X. Built with the official Remotion agent skills (`remotion-dev/skills`): multi-scene `TransitionSeries`, Google Fonts, `Interactive` markup.

```sh
cd launch/remotion
npm install
npx remotion studio --no-open   # preview at the printed URL
npm run render                  # 32s 4K mp4, then muxes the soundtrack
```

Shipped film: `docs/shepherd-launch.mp4`. Post copy is in `POSTS.md`.
